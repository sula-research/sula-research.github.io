# Sula Research

A compact website for quantitative research and trading work, currently published at https://sula-research.github.io/.

## Public pages

- Home: `_layouts/home.html`
- About: `about/index.md`
- Contact: `contact/index.html`
- Client Login: `client-login/index.html`

The contact form and client login are static placeholders. To make contact open an email draft, set `email:` in `_config.yml` to the intended address. The client login needs a separate authentication service before it can accept real users.

## Theme content kept for later

This site uses the Moon Jekyll theme. Its example posts and the old Posts, Projects, and Tags pages remain in the repository so the site can expand later. They are excluded from the published build in `_config.yml` and therefore do not appear in `sitemap.xml`. To restore them, remove `_posts`, `posts`, `projects`, and `tags` from the `exclude` list, then add any desired navigation links.

## Hosting

GitHub Pages builds the site from `main`. The sitemap is generated by `jekyll-sitemap` at https://sula-research.github.io/sitemap.xml. If the site moves to a custom domain or another Jekyll host, update `url` in `_config.yml` and the hosting configuration. The theme and site source can be reused.
